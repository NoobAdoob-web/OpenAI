------------------------------------------------------------------------
1. SINGLE PURPOSE DESCRIPTION   (Dashboard -> Privacy practices -> Single purpose)
------------------------------------------------------------------------
ScrapeSuite lets users export publicly visible social-media posts and
product reviews from a supported page (YouTube, Instagram, Facebook,
LinkedIn, Amazon, Flipkart) into a ranked, analysis-ready CSV/Excel
spreadsheet, with basic on-device analytics.


------------------------------------------------------------------------
2. PERMISSION JUSTIFICATIONS   (Dashboard -> Privacy practices)
------------------------------------------------------------------------

activeTab
  Used to read the content of the tab the user is actively viewing when
  they click the ScrapeSuite icon, so it can detect and extract the posts
  or reviews visible on that page.

scripting
  Used to inject ScrapeSuite's extraction logic into the supported pages
  (and into pages it opens in the background for deep data) so it can read
  the publicly visible post/review content and run on-device image OCR.
  No remote code is injected -- all scripts are bundled in the package.

storage
  Used to remember the user's in-popup settings and in-progress results
  (selected fields, collected rows) so data isn't lost when the popup is
  closed and reopened. Stored locally only.

downloads
  Used to save the exported spreadsheet (CSV / .xlsx) to the user's own
  computer when they click Download.

tabs
  Used to (a) read the active tab's URL to know which supported platform/
  product the user is on, and (b) open a post's or review page in a
  background tab during "Deep Scrape", "Collect reviews", and exact-date
  lookups, then close it after reading the visible data.

offscreen
  Used to run the bundled on-device OCR engine (PaddleOCR PP-OCRv4 on
  onnxruntime-web/WASM), which needs a DOM/canvas + WASM context the service
  worker cannot provide. It is used solely to read text from post images
  locally; no image or text leaves the device.

Host permissions (youtube.com, instagram.com, facebook.com, linkedin.com,
amazon.* , flipkart.com, ytimg.com)
  ScrapeSuite only functions on these specific sites. Access is needed to
  run the content script on the page the user opens, read the publicly
  visible posts/reviews, fetch full-resolution images and post dates from
  those same domains, and open their post/review pages in background tabs
  for complete data. It requests no access to any other websites.

Are you using remote code?  ->  NO
  All executable code, including the OCR engine and its English/Hindi
  language data, is bundled inside the extension package. Nothing is
  fetched or executed from a remote server.


------------------------------------------------------------------------
3. DATA USAGE DISCLOSURES   (Dashboard -> Privacy practices -> Data usage)
------------------------------------------------------------------------
ScrapeSuite processes page content locally on the user's device and only
lets the user download it -- it does NOT transmit any data to the
developer or third parties (there is no backend/server). Under Chrome's
definition, "collection" means obtaining AND transmitting data off the
device, which ScrapeSuite does not do.

Data types collected:
  Select NONE of the categories (no PII, financial info, authentication
  info, personal communications, location, web history, etc.).

Certifications (tick all three):
  [x] I do not sell or transfer user data to third parties, apart from
      the approved use cases.
  [x] I do not use or transfer user data for purposes unrelated to my
      item's single purpose.
  [x] I do not use or transfer user data to determine creditworthiness
      or for lending.

NOTE: Because the extension reads on-screen "website content", a reviewer
might ask you to tick the "Website content" box. If they push back, tick
it and add:
  "Website content (public posts/reviews) is read only to build the
   spreadsheet the user downloads; it is processed entirely on-device and
   never transmitted to us or any third party."
