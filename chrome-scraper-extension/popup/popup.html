ℹ️ How to use this extension
  1. Open a profile page — e.g. a YouTube channel's Videos, an Instagram Reels tab, a Facebook page's Reels, or your LinkedIn feed.
  2. Set Number of scrolls and click Start scraping to auto-scroll and load more posts.
  3. Want likes / comments / shares that aren't on the grid? Tick Deep Scrape, choose the fields, and start it — it opens each post to read the full data.
  4. Click Download Excel (or CSV) to save your data.

Tip: stay logged in to the platform. Keep a 3s+ delay in Deep Scrape to avoid being rate-limited.

⚠ Before you start:
  • Fills the full caption + views/likes/comments/shares for every item — works the same whether you're on Posts or Reels.
  • Opens every post one-by-one — slower (≈ your delay × number of posts).
  • You must be logged in to the platform in this browser.
  • Instagram & YouTube shares are not public — that column stays blank there.
  • Going too fast can trigger anti-bot checks. Keep a 3s+ delay.
  • Runs on the posts already loaded above — scroll first to load more.
⚠ About image reading:
  • Adds Image Text, Content Type (Offer-led / Product-led / Festive / …) and Image Language columns.
  • Reads English & Hindi only. Other scripts (Punjabi, Malayalam, Tamil…) are marked Regional asset.
  • Reads each post's full-size image (not the small thumbnail) for better accuracy — so allow ~2–4s per image.
  • Runs on-device — nothing leaves your browser. Stay logged in.
  • Works on the images already loaded above — scrape first.
