========================================================================
  INSTANT DATA SCRAPER  --  CHANGELOG
========================================================================
The version is shown in the popup header and set in manifest.json.
Downloaded builds are named: chrome-scraper-extension-vX.Y.Z.zip


------------------------------------------------------------------------
v2.6.0  (current)
------------------------------------------------------------------------
- Product reviews: the extension now scrapes Amazon and Flipkart reviews.
  Columns: Rating, Rating (number), Title, Review, Reviewer, Date, Verified,
  Helpful, Helpful (number), Variant, Product, URL. Reviews rank by helpful
  votes (then rating), and the analysis becomes review-aware (review count,
  average rating, % verified, rating breakdown, most-helpful review).
  Amazon uses stable data-hook selectors (reliable); Flipkart is best-effort
  (its class names are obfuscated) — report a page if a field is missed.

------------------------------------------------------------------------
v2.5.0
------------------------------------------------------------------------
- Smart column order: columns that have values come first; columns that are
  blank for this platform/output (e.g. Shares on Instagram/YouTube, or
  Likes/Comments on a basic reels scrape) are pushed to the end. Applies to
  the popup preview, CSV, and both Excel tabs. Paired columns (Views /
  Views (number)) stay together; Rank stays first.

------------------------------------------------------------------------
v2.4.1
------------------------------------------------------------------------
- Fix: "Cannot access '_scriptBlobCache' before initialization" on some
  pages (e.g. Instagram). The grid-date cache variable was declared after
  bootstrap ran; moved it into the top state block so detection no longer
  throws on page load.

------------------------------------------------------------------------
v2.4.0
------------------------------------------------------------------------
- Content Insights: the analysis now cross-analyses captions/content against
  engagement and surfaces PATTERNS, e.g. "Posts that mention an offer/
  discount get 2.1x more comments" or "Posts that mention <brand> get 4x
  more views". Dimensions include offers/discounts, festive themes,
  questions, hashtags, caption length, emojis, @mentions, calls-to-action,
  video length, OCR content type, and the most common caption keyword
  (surfaces brand/product/theme names). Works on views alone (basic scrape);
  likes/comments/shares comparisons unlock with Deep Scrape / LinkedIn.
  Each pointer shows the actual averages so it is transparent, not a guess.

------------------------------------------------------------------------
v2.3.1
------------------------------------------------------------------------
- Exact first/last-post dates now use REAL deep scraping: the extension
  opens the first and last post each in a background tab, lets it render,
  and reads the exact date from the live page (no fetch/guesswork). This
  fixes Instagram where the plain fetch returned no date. Callout warns it
  can take 10-20 seconds.

------------------------------------------------------------------------
v2.3.0
------------------------------------------------------------------------
- Exact date range: after a scrape, the extension fetches the precise
  posting date of the FIRST and LAST post (one quick request each) and
  uses them for the date range + "Date of first/last post". A callout
  warns it may take a few seconds; falls back to grid dates if it can't.
- Text insight pointers in the analysis (popup + Excel): most viewed,
  most liked, most comments, best engagement rate, longest/shortest video.
- Better video length: the first/last fetch also fills in duration when
  the grid didn't have it; duration now shows h:mm:ss for long videos.

------------------------------------------------------------------------
v2.2.0
------------------------------------------------------------------------
- Analysis summary: the popup now shows a stats panel (posts, date range,
  span, posts/week, avg/median/total views, avg duration) and the same
  ANALYSIS block is written at the top of the Excel "Top Performers" tab.
- Date range (earliest -> latest post) is computed so the time window of
  the data is explicit. Handles ISO, "Month DD, YYYY", and relative dates
  ("2 days ago", "2d/3w/1mo").

------------------------------------------------------------------------
v2.1.0
------------------------------------------------------------------------
- Top-performer ranking: the preview now shows posts sorted best-first
  with a Rank column (ranked by Views, or Likes/Comments where a platform
  has no views).
- Excel download now has TWO tabs: "Top Performers" (ranked) and
  "Raw Data" (exactly as scraped). CSV exports the ranked view.

------------------------------------------------------------------------
v2.0.0
------------------------------------------------------------------------
- Image OCR: read on-image text on-device (English + Hindi), added
  columns Image Text, Content Type (Offer-led / Product-led / Festive /
  Informational) and Image Language. Reads each post's FULL-resolution
  image (not the grid thumbnail) with upscale + grayscale + contrast
  preprocessing for better accuracy. Other scripts -> "Regional asset".
- Video Duration + Duration (sec) columns (Meta / Instagram / YouTube).
- Cost per view (CPV) input -> Expected Investment column (CPV x views).
- Upload date now shown in the basic grid scrape (no Deep Scrape needed).
- Deep Scrape fills the full caption + metrics for both posts AND reels.
- Simplified UI: removed "Locate Next Button"; one "Start scraping"
  button with a number-of-scrolls input; added a How-to-use help box.
- Highlight box now shows only while the popup is open.
- Version badge shown in the popup header.

------------------------------------------------------------------------
v1.x  (earlier internal builds)
------------------------------------------------------------------------
- Platform extractors for YouTube / Instagram / Facebook / LinkedIn
  (Caption, Views, Likes, Comments, Shares, Date, URL, Thumbnail) with
  raw + numeric columns.
- Deep Scrape mode (opens each post for likes/comments/shares/date,
  optional comment text) via an offscreen/background pipeline.
- Infinite-scroll collection, CSV + Excel export.
- Fixes for lazy-loaded images, deeply-nested grids, hashed CSS class
  names, Facebook background-image grids, YouTube's new layout, and a
  temporal-dead-zone crash that blocked detection on pages with data.
